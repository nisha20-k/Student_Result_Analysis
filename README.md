# Student Result Analysis System

A Python project that analyzes student marks using NumPy. The project reads data from a CSV file, calculates statistics, assigns grades, identifies top-performing students, and generates a report in CSV format.

---

# Features

- Read student data from CSV file
- Calculate average marks
- Find highest and lowest marks
- Identify topper and lowest scorer
- Pass/Fail analysis
- Grade calculation (A+, A, B, C, D, F)
- Display Top 3 Students
- Generate report.csv automatically
- Grade Statistics

# How to Run

1. Clone the repository

```bash
git clone https://github.com/nishak-20/Student_Result_Analysis.git
```

2. Go to project folder

```bash
cd Student_Result_Analysis
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run the project

```bash
python student_result_analysis.py
```
